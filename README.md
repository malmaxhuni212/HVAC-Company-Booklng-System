An end-to-end automated client intake and management dashboard built specifically for the HVAC industry. MetroWarmth Connect (MetroHeating) eliminates missed calls and manual data entry by deploying an interactive AI voice receptionist that handles customer inquiries, vets service requests, and manages technician scheduling in real time. 

## 🚀 Core Features

*   **24/7 AI Voice Receptionist:** An intelligent AI agent staffs the customer service line around the clock. It automatically qualifies the caller, checks the job against technician availability, and books the appointment directly. This workflow is completed entirely without a human being on call to pick up the phone.
*   **Automated Scheduling Engine:** Seamlessly books emergency or routine maintenance calls directly into technician calendars using Cal.com infrastructure.
*   **Centralized Intake Dashboard:** A fast, responsive interface that provides immediate visibility into caller transcripts, client service history, and real-time appointment status.
*   **Lead & Revenue Capture:** Designed to catch incoming inquiries that would have gone to voicemail and failed to convert. By capturing these lost leads, AI call-answering tools can pay for themselves with as little as one job booked each month.

## 🛠 Tech Stack

*   **Frontend & UI:** Lovable, React, Tailwind CSS
*   **Voice AI Integration:** Retell AI (for interactive, natural-sounding conversational phone agents)
*   **Scheduling Infrastructure:** Cal.com API
*   **Backend & Database:** Supabase (PostgreSQL for secure client and appointment data storage)

## 📦 Getting Started

### Prerequisites
Ensure you have Node.js (v18+) and npm installed. You will also need active API keys for Retell AI, Supabase, and Cal.com
